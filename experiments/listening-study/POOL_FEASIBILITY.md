# Возможность 6 A/B и 2 C/D троек — предварительная оценка

**По числу публикаций и авторских групп — потенциально возможно. По музыкальным условиям и допущенным записям — пока не установлено.** Сейчас 0 измеренных отрывков, 0 разрешённых локальных файлов и 0 прошедших ручную проверку троек. Нельзя запускать `screen` на этих подсказках и считать его ответ доказательством слушательского сходства.

Квоты — предложение для фиксации **до отбора по ответам**, ещё не программно выполненная оптимизация. Для 8 троек нужны 24 уникальные записи. Цель: минимум 7 независимых авторских групп, максимум 4/24 (16,7%) от одной группы, не более двух исходных песен одного автора; внутри тройки все три автора разные. По возможности использовать 8–9 групп и максимум 3 записи автора. Два исполнения из одного произведения Open Goldberg не использовать одновременно; общий тематический материал создаёт дополнительную зависимость.

Идентичные записи в другом контейнере/с другим названием не становятся новым стимулом: сверять источник, мастер, SHA256 и слушать; byte-hash сам по себе не распознает перекодированную копию. Для псевдонимов использовать `creator_id`, а не разные строки `artist`. Известные Monplaisir/Komiku/Loyalty Freak Music/Alpha Hydrae — одна группа Rrrrrose. [Авторская страница](https://rrrrroseazerty.neocities.org/posts/a-content-id-story) и ссылки альбомов связывают эти публикации. Независимость здесь означает разные установленные авторские группы, не статистическую независимость музыкальных записей.

При исключении всех разночтений и индексных заявлений остаются **14 подтверждённых CC0-публикаций четырёх новых авторских групп** (10 отдельных записей + 4 записи именованного альбома). Этого **недостаточно для 24 разных стимулов**, даже до проверки звука. Поэтому число 44 не означает готовность пилота. Нужны устранение разночтений, проверка недоступных источников либо дополнительные независимые публикации до верхнего предела 60.

Предварительные связи для проверки, **не предложенные готовые тройки**:

| Область поиска | Записи разных авторов с подсказками | Неизвестное, которое может разрушить подбор |
|---|---|---|
| Гитара, бас, ударные / рок и фанк | h01/h02/h05, j07, o01, k01/k02 | Инструменты h неизвестны; «Funk» и «Rock» не доказывают близкую инструментовку; энергия и ритм всех отрывков неизвестны |
| Пиано и акустические тембры | j01/j04, s01/s02, i01/i02 | Соло и ансамбль могут оказаться слишком разными; рубато, неопределённый BPM и общие темы; обе i-альтернативы не включать |
| Чиптюн / электронная музыка | h07/h08, o02/o03, k04 | 8-bit/Chiptune не определяет синтезатор или тембр; «Bossa Nova» не гарантирует акустическую запись; длина o03 неизвестна |
| Оркестровые / атмосферные записи | j08, s03/s04, o04, u01/u02, t01–t04 | Альбомные теги t слишком широки, инструменты t/u неизвестны; s03 — подсказки на уровне двух треков; нельзя объявлять их одинаковыми |

Для A/B особенно важно найти у каждого из **6 разных исходных отрывков** кандидата A с близкими измеренными ритмом/темпом/энергией и различающейся разметкой жанра/инструментов, и B с обратным сочетанием. Для оставшихся **2 исходных отрывков** нужны C (близки оба блока) и D (отличаются оба). Это 8 исходных + 16 кандидатов без повторов; ни одной конкретной расстановки сейчас не утверждаем.

Порядок проверки:

1. Подтверждение прав и короткий список; независимое прослушивание двумя проверяющими, фиксация расхождений. Ввести общий словарь положительных жанровых/инструментальных тегов и заморозить правила разметки: регистр, `Kit`/`drum kit`, `EP`/`electric piano`, `Synth`/`synths`. Хранить исходные теги и происхождение; не переносить альбомные подсказки в индивидуальные без проверки. Неизвестное остаётся неизвестным, особенно для условий «отличается».
2. Получить только разрешённые выбранные файлы, выделить сопоставимые 15-секундные участки без речи/резких входов по одинаковым правилам. Выполнить существующий `prepare` и сохранить реальные признаки, сырые/предъявленные уровни и hashes. Проверить BPM и half/double-time на слух; не выбирать удобный алиас ради нужной категории. Нет надёжного темпа — не подставлять число.
3. Использовать существующие пороги `screen` без скрытого ослабления; вручную проверить все A/B/C/D кандидаты. Из подходящих троек выбрать 6 основных и 2 контрольных с квотами выше. Проверить глобальную уникальность записи и распределение авторов по ролям: один автор не должен систематически означать «ритмический» или «жанровый» кандидат. Где возможно, разница числа его A и B появлений ≤1.
4. Если нет 8 троек, расширять источник/пул до начала ответов, а не дублировать записи или объявлять отсутствие тегов отличием. Зафиксировать новую ревизию пула/разметки/стимулов и причину. Затем `review` → `freeze`, отдельный технический претрест 3–5 человек. Их ответы не смешивать с основным пилотом и не использовать скрытно для подтверждения гипотезы.

32 участника дают 16 человек на формулировку и 8 заданий каждому, а не 256 независимых участников. Из-за малого числа исходных песен и ограниченного авторского разнообразия исследование остаётся пилотным: сохраняются кластерные интервалы по участникам, чувствительность к песням и раздельные формулировки. Эти оценки не заменяют расширение пула.
