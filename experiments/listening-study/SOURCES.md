# Источники и допуск аудио

Проверено 2026-10-09; MTG Git revision `cafd8e20c265ed84f1e61f1c875327971f43a62f`.

MTG-Jamendo содержит более 55 тысяч полных треков с тегами загрузивших их пользователей. Базовый autotagging-набор использует 195 тегов из категорий genre, instrument и mood/theme; поднаборы и train/test splits имеют разное покрытие. Для исследования использовать один закреплённый общий TSV, не соединять неполные поднаборы как отрицательную разметку. Структура — track/artist/album ID, путь, длительность и переменное число полей тегов `category---value`. `raw.meta.tsv` содержит отображаемые метаданные; они не нужны интерфейсу слушателя. [README MTG](https://github.com/MTG/mtg-jamendo-dataset), [официальный TSV parser](https://github.com/MTG/mtg-jamendo-dataset/blob/cafd8e20c265ed84f1e61f1c875327971f43a62f/scripts/commons.py).

Код датасета — Apache 2.0, метаданные — CC BY-NC-SA 4.0, аудио — индивидуальные лицензии из `audio_licenses.txt`. README ограничивает датасет некоммерческим исследовательским/академическим использованием и требует письменного разрешения Jamendo для иных применений, включая коммерческую интеграцию. **Listening Study не означает, что такое разрешение уже получено.** [Лицензии MTG](https://github.com/MTG/mtg-jamendo-dataset#license), [потрековый ledger](https://github.com/MTG/mtg-jamendo-dataset/blob/master/audio_licenses.txt).

До получения реальных файлов нужно проверить конкретную лицензию, область исследования и разрешение на наши действия. Сохранить правообладателя, URL/документ-доказательство, дату проверки, атрибуцию, лицензию и явные разрешения на анализ, вырезание/изменение уровня, локальное воспроизведение и слепой показ. Если нельзя совместить требования к указанию автора со скрытыми названиями во время выбора, согласовать допустимый порядок атрибуции (например, после сессии), получить отдельное разрешение либо исключить запись. UI сам не показывает реальный список атрибуций — оператор обязан обеспечить согласованный вариант отдельно.

NC не следует автоматически считать разрешением на исследование продукта. SA влияет на условия распространения адаптаций; ND требует отдельной проверки применимости к нарезке/обработке. Эта реализация использует консервативный допуск: все четыре разрешения должны быть явно проверены; статус «неизвестно» не проходит. См. [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) и [CC BY-NC-ND 3.0](https://creativecommons.org/licenses/by-nc-nd/3.0/); полный текст конкретной лицензии важнее краткого описания. Это операционные требования к пилоту, не заключение о правах на конкретную запись.

Массовый загрузчик MTG не запускается. Нет аудио, реальных рядов метаданных или лицензированных записей в PR/CI. Разрешённые будущие файлы пользователь передаёт локально по явному allowlist. Синтетические сигналы генерируются из осцилляторов, без сэмплов, и не считаются музыкой MTG. До реального пилота требуется отдельное подтверждение выборки и прав.
