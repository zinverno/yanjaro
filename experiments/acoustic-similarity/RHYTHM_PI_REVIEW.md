# Независимая проверка rhythm retrieval — протокол, NOT RUN

Участники не приглашались, ответы не назначались. Никаких новых загрузок или
публикации аудио. До проведения отдельно подтвердить локальную процедуру доступа
к тем же разрешённым CC0-файлам; этот документ не разрешает удалённую передачу.

Заморозить PI-v1 и исторический DSP baseline до ответов. Использовать только
сохранённые 15-секундные окна, без расширения. Все три фрагмента звучат целиком;
никакого time-stretch, подбора фазы или BPM по ответам. Возможная одинаковая
нормализация громкости для прослушивания должна быть отдельно зафиксирована,
без изменения сохранённых файлов или исследовательских признаков.

Ключ `validation/rhythm-pi-v1/review-cases.json` содержит 12 уникальных triplets:
по одному для каждого исходника — первые соседи PI/DSP при разногласии либо два
первых PI-соседа при совпадении; ещё два случая с малым разрывом первых PI-соседей.
Seed перестановки A/B: 20261014. Ни один triplet не содержит повтор исходника.
Добавить два слепых повтора из r01 и r02 с перестановкой A/B, всего **14 предъявлений**.
Перемешать порядок отдельно для каждого рецензента, сохранить seed. Ключ алгоритма,
названия, авторы, жанры, ранги, численные scores и правильные ответы отсутствуют
в интерфейсе. Ключ в репозитории предназначен организатору, не участнику.

Минимально два независимых рецензента, третьего приглашать только отдельным
решением для разногласий. Не собирать имена, музыкальные предпочтения или историю
прослушиваний: достаточно случайного reviewer ID. Можно пропустить любой вопрос
или отозвать ответы. Пока это предложение будущей оценки, а не набор участников.

Единственный содержательный вопрос:

> Какой фрагмент, A или B, акустически ближе к X по ритму — повторяемости и
> расположению атак, акцентам и пульсу? Не выбирайте любимую песню и не оценивайте
> жанр или качество композиции.

Ответы: **A / B / оба примерно одинаково / ни один / не могу определить**.
Отдельно можно отметить мешающий тембр/неясный пульс и уверенность
низкая/средняя/высокая; уверенность не заменяет независимое согласие.

До чтения ответов определить отчёт: coverage ответов, количество A/B/tie/neither/
uncertain, согласие рецензентов, согласие на слепых повторах, доля сравнений,
согласованных с каждой системой **на этих отобранных случаях**. Не превращать
tie/neither/uncertain в отрицательные labels. Хранить исходные ответы и правила
агрегации, показывать исключения. Не делать learned weights из этого pilot.

Выборка преднамеренно информативная, всего десять записей и три группы авторов.
Она не оценивает population accuracy и не даёт retrieval recall: полного множества
релевантных песен нет. Для recall нужны независимые relevance labels на полном
фиксированном пуле кандидатов. Для подтверждающего эксперимента понадобятся
новые разрешённые независимые записи и отдельное согласование; открытые GMD
drummer6/drummer8 tests для этого не подходят.
