# Подбор Yanjaro · эксперимент (v0)

Это отключаемый конечный микс до 30 песен с локальными правилами отбора. Каталог и аудио предоставляет Яндекс. «Моя волна» не используется как генератор; собственной модели аудиосходства, BPM/energy/embeddings и измеренного превосходства нет. Включение — только в настройках аккаунта. В выключенном режиме запросы эксперимента и сбор локальных событий не выполняются.

По нажатию «Собрать новый» берутся до 60 случайно выбранных ID из всей коллекции и явно выбранных исходных треков (до 10). Запрашиваются их метаданные, затем не более двух страниц по 20 треков знакомых исполнителей и одного альбома (до 40 кандидатов из ответа). Всего до пяти запросов SDK, включая чтение любимого при холодном старте; в памяти не более 180 кандидатов. Запросы идут по одному, после ожидающих запросов воспроизведения/интерфейса. Уже начатый сетевой вызов не прерывается насильно: timeout 8 секунд, поздний ответ выключенного режима отбрасывается. Следующих фоновых шагов после выключения нет.

tracks_similar/artists_similar пока не включены: документированных методов недостаточно без живой проверки. Поэтому интерфейс прямо сообщает режим «коллекция и знакомые исполнители/альбомы». Пустая коллекция предлагает добавить исходные треки из обычного поиска. История Яндекса не нужна.

Правила v0 — гипотезы: отфильтровать недоступное, локальные запреты, дубликаты и последний действительно прослушанный трек; затем учитывать баланс знакомого/нового, связь с исходными исполнителями, оценки, давность и слабый сигнал раннего ручного пропуска. Веса: знакомое/новое до 2, оценка ±3, знакомый исполнитель +0.7, давность до +0.5, очень недавнее до −2, ранний ручной пропуск −0.2 (не более −0.6), небольшое seed-воспроизводимое разнообразие до 0.2. Оценка не превращает пропуск в запрет. Жадная сборка не ставит одного исполнителя подряд и ограничивает каждого тремя треками. Если пул слишком мал, микс короче 30, без заполнения дублями. Причина в строке соответствует реально использованному происхождению, а «давно не слушали» появляется только при локальном событии старше семи дней.

«Больше такого», «Меньше такого», «Не предлагать» и снятие оценки относятся к текущему треку и меняют только локальный эксперимент, не лайки/дизлайки Яндекса. Оценки влияют на следующую сборку. Обычные repeat/shuffle доступны для полученного конечного микса.

Профиль хранится отдельно по хешу UID в `$XDG_STATE_HOME/yanjaro/<account>/experiment.json` (по умолчанию `~/.local/state`). Минимальное событие: ID трека, внутренний ID запуска для дедупликации, время, источник, реально прослушанные секунды и причина окончания. Учёт использует монотонные интервалы наблюдаемого состояния mpv, а не разницу позиции: пауза, seeking и buffering не добавляют время. Закрытие, ошибка и смена источника не являются отрицательной оценкой. Корректная отдельная обратная связь настоящих станций сохранена.

События и оценки старше 90 дней удаляются при следующем запуске/записи; максимум 5000 событий и 2000 оценок. Выбранные исходные ID и настройки остаются до очистки. «Очистить данные эксперимента» удаляет события, оценки, исходные ID и текущую выдачу; выключение прекращает дальнейший сбор. Профиль не входит в исходники/пакеты/диагностические снимки. Сервер Yanjaro, LLM, платные API и анализ всего аудиокаталога отсутствуют.

Автоматическая проверка: фиксированный seed, дедупликация, запреты, соседние/частые исполнители, влияние оценки, пустой/малый пул, ошибка источника, лимит вызовов, выключение во время запроса, фактические интервалы pause/seek/buffering, однократная запись запуска и retention. Живая оценка качества NOT RUN: нужны несколько сессий рядом с обычным shuffle любимого и мнение пользователя. Ручные пропуски и новые сохранения — только наблюдения малой выборки, не проценты улучшения и не причинный эффект. Качество этого эксперимента не блокирует исправления A/B.

Функциональная живая проверка на установленном rc2-1 прошла: владелец подтвердил сборку/воспроизведение микса, локальную оценку и выключение; сохранён реальный снимок 30 треков. Это не сравнительная оценка качества рекомендаций.
