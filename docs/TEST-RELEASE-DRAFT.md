# Yanjaro 0.2.0rc4 — первый публичный тест

Локальный черновик: Release и тег пока не созданы, публикация требует отдельного разрешения владельца.

Неофициальный клиент Yandex Music / Яндекс Музыки для Manjaro x86_64. Предварительный выпуск **0.2.0rc4-1** для тестирования, не стабильная 0.2.0 и не обещание поддержки всех Linux.

Доступны любимое с добавлением/снятием отметок, поиск треков/исполнителей/альбомов, страницы каталога, станции и «Моя волна» с автоматическим продолжением, очередь, repeat/shuffle для конечных списков, сохранение входа через Secret Service и системное управление MPRIS. Previous теперь сначала возвращается по реальным переходам, затем идёт назад по полной очереди; Next возвращает вперёд. Добровольный «Подбор Yanjaro · эксперимент» собирает конечный микс из кандидатов каталога по локальным правилам; превосходство над «Моей волной» не доказано.

Нужен аккаунт с доступом к полным трекам: подписку и региональные ограничения определяет сервис. Клиент не обходит ограничения доступа и не заменяет полный трек превью. Проверен аккаунт владельца; универсальная совместимость аккаунтов не заявляется.

Ручная финальная приёмка rc4-1 владельцем: 5/5 PASS, включая Previous/Next, быстрые переходы, сохранение паузы и настоящую MPRIS-карточку. Manjaro Stable x86_64, Python 3.14.7, Qt/PySide6 6.11.2, mpv 0.41, SDK 3.2.0. Отдельно прошли чистые Arch/Manjaro сборка/check, установка, обновление с rc3-1, headless-запуск и удаление. CI с offscreen/ao=null не доказывает слышимый звук или устройство рабочего стола; для них используется отдельный результат владельца. Это не новая полная проверка всех аккаунтов и оборудования.

В папке загрузки после проверки происхождения:

```sh
sha256sum -c SHA256SUMS
sudo pacman -U ./yanjaro-0.2.0rc4-1-any.pkg.tar.zst
/usr/bin/yanjaro
```

Пакет использует системные Qt/mpv и Python-библиотеки; pacman разрешает зависимости из репозиториев Manjaro. Это не автономный установщик. Закройте старое окно до обновления. Запуск также доступен через меню Yanjaro Music. Для удаления — `sudo pacman -Rns yanjaro`, предварительно проверьте предложенный список зависимостей. Обновление не удаляет вход и настройки.

Токен хранится только в системном Secret Service, пароль не сохраняется. При недоступном хранилище доступен явно обозначенный сеансовый вход. Logout удаляет секрет; удаление пакета не очищает личную связку ключей или XDG-данные. Настройки: `$XDG_CONFIG_HOME/yanjaro` (обычно `~/.config/yanjaro`), локальные данные: `$XDG_STATE_HOME/yanjaro` (`~/.local/state/yanjaro`), кэш: `$XDG_CACHE_HOME/yanjaro` (`~/.cache/yanjaro`). Данные эксперимента разделены по аккаунтам, ограничены 90 днями и очищаются в настройках.

Каталог, аудио и отчёты прослушивания/радио обращаются к Яндексу. Отдельного сервера аналитики Yanjaro в проверенном коде нет; это не заявление об отсутствии сетевых обращений. История сервиса скрыта; offline, lossless, Ynison, Acoustic Intelligence и Music Lab не входят в этот выпуск. Repeat/shuffle отключены для бесконечных станций. После ограниченного повтора сетевого запроса окончательная ошибка показывается пользователю; внешняя причина прежнего ConnectTimeout не установлена.

Ошибки: [Issues проекта](https://github.com/zinverno/yanjaro/issues). Укажите версию из `pacman -Q yanjaro`, окружение, шаги и безопасный текст сообщения. Не прикладывайте токены, cookies, коды входа, аудиоссылки, HTTP-дампы, keyring, личные базы или рабочий стол с приватными уведомлениями.
