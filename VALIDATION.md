# Проверка UI и локального пакета — 2026-10-07

**Кандидат 0.2.0rc1 не объявлен готовым к публичному выпуску.** Автоматические проверки, прежние ответы пользователя об исходной версии и новая приёмка пакета разделены ниже. Данные тестов не подаются в обычный режим приложения.

## Исходное состояние

- Проверены исходники: Python / PySide6 Qt Quick, `MusicApi` с yandex-music 3.2.0, `Player` с настоящим libmpv, один `ThreadPoolExecutor` для сетевых вызовов. Стек не заменён; вход, API-пути и получение полного аудио сохранены.
- До изменений: **17 тестов PASS**; архив исходников `/tmp/yanjaro-before-ui-20261007.tar.gz`.
- Исходная `.git` пустая и защищена от записи, её содержимое сохранено. По последующему запросу владельца создан приватный [zinverno/yanjaro](https://github.com/zinverno/yanjaro), независимый клон `/tmp/yanjaro-git` и ветка `feature/desktop-ui-and-packaging`. Исходная работа сохранена коммитом `e935957` в `main`, UI — отдельным коммитом `277b33a`, упаковка — следующим логическим коммитом. Reset, force-push, merge и публичный выпуск не выполнялись.
- История исходной проверки с аккаунтом сохранена целиком в [VALIDATION-0.1.md](docs/VALIDATION-0.1.md). История скрыта из навигации; API и данные на сервере не удалены и не подменены.

## Сценарии

Новый UI из исходников пользователь проверил после запуска `./run.sh`: «есть небольшие мелочи которые исправлю уже следующим заходом, все главное работает нормально». Это подтверждение предложенного основного сценария (выбор/запуск, поиск и навигация с музыкой, громкость, очередь и «Моя волна»), без отдельного протокола каждого действия. Оно не подтверждает установку пакета, границу API-партии, все масштабы или отказы сети. Мелкие замечания оставлены на следующий этап по решению пользователя.

## Автоматический прогон

- **29 unittest-тестов**: API-контракты с синтетическими ответами и настоящие Qt/libmpv проверки без аккаунта. Команда в README.
- `pyside6-qmllint yanjaro/*.qml`: PASS, без предупреждений.
- `desktop-file-validate packaging/yanjaro.desktop`: PASS.
- Состав нативного пакета: PASS — entry point, UI, иконки и лицензии; нет `.venv`, `.runtime`, тестовых фикстур, личных баз, логов, env/key-файлов. Код не зависит от домашнего каталога автора. Сканер не читает пользовательские секреты; SDK отдельно закреплён по хешу официального wheel.
- Native package создан `makepkg --nodeps --nocheck` на Manjaro Stable x86_64. **Это не чистая сборка и не проверка установки зависимостей.** Основной прогон тестов выполнен отдельно в `.venv`.
- В отдельном `/tmp` root пакет установлен pacman в user namespace; зависимости в этой проверке намеренно пропущены, скрипты/хуки отключены. Основная система не менялась. Тест запуска использовал библиотеки из `.venv` и локальный libmpv; private SDK и QML загружались именно из установленного пакета. Проверены CPython 3.13 и системный 3.14 без его модификации. IPC заменён тестовым адаптером, аккаунт не использован.
- Обновление в изоляции: PASS, pacman обновил локальный кандидат `0.2.0rc1-1` до `0.2.0rc1-2`; после обновления entry point, private SDK, Qt и libmpv снова запущены. Это проверка локальных кандидатов с внешними тестовыми зависимостями, не обновление опубликованной версии и не живая проверка аккаунта.
- Удаление в изоляции: PASS, pacman удалил команду, desktop-файл и модули из тестового root. Основная система не менялась.
- Чистая сборка/установка со всеми зависимостями в Manjaro Stable VM и Arch chroot: **NOT RUN** — нет подготовленной чистой среды с полным набором целевых пакетов.
- `namcap`: **NOT RUN**, инструмент отсутствует. AppStream validation: **N/A**, metainfo не добавлялся, он необязателен для выбранного локального канала.
- Живые снимки любимого/поиска/станций: **NOT RUN**. В README только реальный экран входа из пакета без аккаунта. Помеченные тестовые снимки в `/tmp/yanjaro-ui-evidence` — отдельное техническое доказательство компоновки.

## Зависимости и публикация

По локальной неизменённой базе pacman, настроенной на **Manjaro Stable**: Python 3.14.7, pyside6/shiboken6 6.11.2-1, Qt Quick/SVG/Wayland 6.11.2-1, python-mpv 1.0.8-2, mpv 0.41.0-6, requests 2.34.2-1, PySocks 1.7.1-12 и typing-extensions 4.16.0-1. Это снимок каталога, не результат свежего `pacman -Sy`. В Arch проверены официальные страницы [pyside6](https://archlinux.org/packages/extra/x86_64/pyside6/) и [python-mpv](https://archlinux.org/packages/extra/any/python-mpv/); чистая Arch-сборка не выполнялась.

SDK 3.2.0 отсутствует в локальном репозитории Manjaro; рецепт включает его официальный pure-Python wheel с SHA-256 в приватный каталог приложения. **AUR-зависимостей у подготовленного рецепта нет.** Имя `yanjaro` проверено через официальный AUR RPC 2026-10-07: `resultcount: 0`, точного пакета на момент запроса нет. Это не резервирование имени; перед отправкой проверить повторно.

Публичный выпуск **BLOCKED**: лицензия GPL-3.0-or-later выбрана и приватный remote создан, но общедоступного неизменяемого URL исходников пока нет. PKGBUILD использует существующий локальный архив и точный хеш, не плавающий main и не выдуманный тег. `.SRCINFO` создаётся makepkg. PAMAC-поиск до публикации **NOT RUN**; после публикации и обновления метаданных отдельно проверить `yanjaro`, `yandex music`, `яндекс музыка`.

Точные артефакты, команды и чек-лист: [RELEASE.md](docs/RELEASE.md). Установка в основной системе требует отдельного согласования. Release, AUR, теги и merge не выполнялись. Загрузка кода в приватный GitHub-репозиторий отдельно разрешена владельцем.
